# install
How to Install this Web Slice Template

> [!IMPORTANT]
> Before installing, please support me by subscribing to my YouTube channel by [CLICKING HERE](https://youtube.com/user/warrenwoodhouse).
> If you have any further questions or would like to give some feedback, please [CLICK HERE](https://warrenwoodhouse.blogspot.com/feedback).

1. Download my template in the form of the ZIP Folder or if you're considering forking this repository, follow Step 4.
2. Once you've downloaded the ZIP Folder, you can install it either through your host provider or via GitHub, your choice.
3. Once installed, make changes how you see fit. Profile Pictures are in PNG format and have a width & height of 160 x 160 px.
4. [CLICK HERE](https://github.com/warrenwoodhouse/slice.git) to clone/fork the repo.
